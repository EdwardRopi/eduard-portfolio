# Twelve Sites — сайт веб-студии

Одна страница, которую можно отправить клиенту вместо разговора: кто мы,
что делаем, сколько стоит, двенадцать работ с превью, команда, ответы на
частые вопросы и форма заявки.

Статика без сборки: HTML + CSS + JavaScript. Чтобы посмотреть локально,
достаточно открыть `index.html` в браузере — шрифты лежат внутри проекта,
интернет не нужен.

- Живой адрес: https://eduard-portfolio-3vt3.onrender.com
- Репозиторий: https://github.com/EdwardRopi/eduard-portfolio (автодеплой с `main`)

## Структура

```
index.html            вся страница: шапка, первый экран, услуги, работы,
                      цены, процесс, команда, вопросы, контакты
privacy.html          политика обработки данных (на неё ссылается форма)
styles.css            палитра обеих тем, типографика, блоки по порядку страницы
script.js             списки WORKS, PRICES, TEAM + фильтр, просмотр, форма, фон
favicon.svg           значок: двенадцать кадров, один из них цветной
assets/fonts/         Geologica, Golos Text, IBM Plex Mono — лежат локально
assets/shots/         снимки сайтов, по три на работу
tools/screenshots.js  снять новые скриншоты (см. ниже)
render.yaml           конфигурация статического сайта для Render
```

## Что правится чаще всего

Все списки лежат в начале `script.js` — правятся руками, без сборки.

**Работы — массив `WORKS`.** Порядок в массиве = порядок на странице и номера
кадров. Как добавить работу — ниже отдельным разделом.

**Цены — массив `PRICES`.** Три пакета; у среднего стоит `popular: true`,
из-за этого он подсвечен и помечен «чаще всего берут». Меняются названия,
суммы, сроки и состав.

**Команда — массив `TEAM`.** Чтобы добавить человека:

```js
{
  name: 'Имя Фамилия',
  role: 'Чем занимается в студии',
  about: 'Одна-две строки о человеке.',
  photo: 'assets/team/ivan.jpg',   // строку можно убрать — тогда покажутся инициалы
  tint: 'var(--c-3)',              // цвет плашки: --c-1 … --c-6
}
```

Фотографии кладите в `assets/team/`, квадратные, 400×400 достаточно.
Последней карточкой в разделе всегда идёт пунктирная плашка «под задачу
подключаем» — она собирается в `fillTeam()`, если больше не нужна, удалите
этот кусок.

## Форма заявки

Пока в `script.js` пустая строка `FORM_ENDPOINT = ''`, форма никуда не
отправляет: она проверяет поля и честно предлагает написать в Telegram.
Чтобы включить отправку на почту:

1. Заведите бесплатную форму на [formspree.io](https://formspree.io/),
   там дадут адрес вида `https://formspree.io/f/xxxxxxx`.
2. Вставьте его в `FORM_ENDPOINT`.

Больше ничего менять не нужно — поля, проверки и сообщения уже написаны.

## День и ночь

Две темы: день — бумага контрольного листа, ночь — светостол, на котором
работы просматривают как слайды. Переключатель в шапке, три режима: авто
(по системной настройке), день, ночь. Выбор запоминается в `localStorage`.

- Цвета — переменные в начале `styles.css`: дневные в `:root`, ночные в
  `:root[data-theme="dark"]` и то же самое в блоке
  `@media (prefers-color-scheme: dark)` — на случай, если скрипт не отработал.
- Ночь не инверсия дня: тона осветлены отдельно, иначе синий и фиолетовый
  проваливаются на тёмном.
- Фирменный цвет работы ночью осветляется через `--tone`, иначе тёмная
  кромка карточки на графите не видна.
- В `<head>` стоит короткий скрипт, который выставляет тему **до** первой
  отрисовки — без него страница моргает белым.
- Смена темы идёт кругом от нажатой кнопки (View Transitions API).

## Живой фон

Рисуется на `<canvas class="bg">` функцией `paintBackground()` в конце
`script.js`: шесть больших пятен печатной краски расходятся и тянутся за
курсором, поверх летят мелкие цветные метки. Настройки там же: `INKS`,
число меток, `globalAlpha`. Фон лежит на `z-index: -1`, поэтому всегда
остаётся под содержимым; при системной настройке «уменьшить движение»
рисуется один статичный кадр, во вкладке в фоне анимация не идёт.

## Как добавить новую работу

1. Снимите три картинки и положите их в `assets/shots/`:

   | файл | что это | размер |
   | --- | --- | --- |
   | `<id>-hero.jpg` | первый экран, превью карточки | 1200×750 |
   | `<id>-full.jpg` | вся страница одной картинкой | ширина 1000 |
   | `<id>-phone.jpg` | телефонный вид | 390×844 |

   Важно: перед **каждым** снимком страницу нужно прокрутить до низа и вернуть
   наверх. Иначе блоки с анимацией появления не успевают проявиться и первый
   экран попадает в кадр недособранным. Скрипт ниже делает это сам.

2. Допишите объект в массив `WORKS`:

```js
{
  id: 'novyi-sait',                 // совпадает с именем файлов
  name: 'НАЗВАНИЕ',
  field: 'Чем занимается бизнес',
  kind: 'card',                     // landing | card | shop — по нему работает фильтр
  accent: '#0B4A7A',                // фирменный цвет сайта, берётся из самого макета
  idea: 'Одна фраза: чем эта работа отличается',
  desc: 'Два-три предложения для окна просмотра.',
  bullets: ['Что внутри', 'Ещё пункт', 'И ещё'],
  tags: ['HTML', 'CSS', 'JavaScript'],
  live: 'https://адрес.ru',         // строку можно убрать, если сайт не опубликован
}
```

## Как снять скриншоты

Нужен Node.js и установленный Playwright:

```
node tools/screenshots.js novyi-sait "C:\путь\к\сайту\index.html"
node tools/screenshots.js novyi-sait "https://адрес.ru"
```

Если на сайте есть плашка про cookie, закройте её вручную — или добавьте
клик в скрипт.

## Деплой

Render, Static Site, автодеплой с ветки `main`: любой пуш обновляет сайт.
Важно: `staticPublishPath` должен быть `./`, а не `.` — с точкой Render
рапортует об успешном деплое, но заливает пустой каталог.

Если после деплоя часть файлов отдаёт 404 вперемешку с 200 — это известная
беда Render со статикой. Лечится повторным деплоем со сбросом кеша
(`POST /v1/services/{id}/deploys` с телом `{"clearCache":"clear"}`).
