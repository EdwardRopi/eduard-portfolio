# Портфолио — сайты для малого бизнеса

Одна страница, которую можно отправить клиенту вместо списка ссылок: 12 работ,
у каждой — превью первого экрана, снимок всей страницы и телефонный вид.
Карточка при наведении проматывает сайт целиком, по клику открывается
полноразмерный просмотр.

Статика без сборки: HTML + CSS + JavaScript. Чтобы посмотреть локально,
достаточно открыть `index.html` в браузере — шрифты лежат внутри проекта,
интернет не нужен.

## Что заменить перед отправкой клиенту

1. **Контакты.** В `index.html` найдите блок между строками
   `▼▼▼ ЗАМЕНИТЕ КОНТАКТЫ НА СВОИ ▼▼▼` и `▲▲▲ …` — там четыре ссылки:
   Telegram, WhatsApp, телефон и почта. Сейчас в них заглушки.
2. **Имя в шапке и подпись в подвале** — если захотите другую формулировку.

## Структура

```
index.html            разметка и все тексты, кроме карточек работ
styles.css            палитра, типографика, блоки в порядке страницы
script.js             массив WORKS (все работы), фильтр, лента, просмотр
favicon.svg           значок вкладки
assets/fonts/         Geologica, Golos Text, IBM Plex Mono — лежат локально
assets/shots/         снимки сайтов, по три на работу
tools/screenshots.js  снять новые скриншоты (см. ниже)
render.yaml           конфигурация статического сайта для Render
```

## Как добавить новую работу

1. Снимите три картинки и положите их в `assets/shots/`:

   | файл | что это | размер |
   | --- | --- | --- |
   | `<id>-hero.jpg` | первый экран, превью карточки | 1200×750 |
   | `<id>-full.jpg` | вся страница одной картинкой | ширина 1000 |
   | `<id>-phone.jpg` | телефонный вид | 390×844 |

   Важно: перед **каждым** снимком страницу нужно прокрутить до низа и вернуть
   наверх. Иначе блоки с анимацией появления не успевают проявиться и первый
   экран попадает в кадр недособранным — заголовок обрезан, половина элементов
   не на месте. Скрипт ниже делает это сам.

2. Допишите объект в массив `WORKS` в начале `script.js`. Порядок в массиве =
   порядок на странице и номера кадров.

```js
{
  id: 'novyi-sait',                 // совпадает с именем файлов
  name: 'НАЗВАНИЕ',
  field: 'Чем занимается бизнес',
  kind: 'card',                     // landing | card | shop — по нему работает фильтр
  accent: '#0B4A7A',                // фирменный цвет сайта, берётся из самого макета
  idea: 'Одна фраза: чем эта работа отличается',
  desc: 'Два-три предложения для окна просмотра.',
  bullets: ['Что внутри', 'Ещё пункт', 'И ещё'],
  tags: ['HTML', 'CSS', 'JavaScript'],
  live: 'https://адрес.ru',         // строку можно убрать, если сайт не опубликован
}
```

## Как снять скриншоты

Нужен Node.js и установленный Playwright. Скрипт снимает три кадра сразу:

```
node tools/screenshots.js novyi-sait "C:\путь\к\сайту\index.html"
node tools/screenshots.js novyi-sait "https://адрес.ru"
```

Перед съёмкой он прокручивает страницу до конца, чтобы сработали анимации
появления блоков, и складывает файлы в `assets/shots/`. Если на сайте есть
плашка про cookie, закройте её вручную — или добавьте клик в скрипт.

## Деплой

Хостится на Render как Static Site: без команды сборки, публикуемая
директория — корень репозитория (`render.yaml`). Важно: `staticPublishPath`
должен быть `./`, а не `.` — с точкой Render рапортует об успешном деплое,
но заливает пустой каталог.

Картинки занимают около 7 МБ, снимок всей страницы подгружается только при
наведении на карточку — на телефоне страница остаётся лёгкой.
